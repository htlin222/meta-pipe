    About this interface
    
    
    
      This is a thin web interface for meta-pipe. It walks through the pipeline stage by stage so you can see, at a glance,
      what each stage produces and where the pipeline pauses for human input — typing the
      research question, uploading a paywalled PDF, confirming the analysis type, signing off on extraction and GRADE.
      It replays the bundled ici-breast-cancer example, so the whole flow is easy to follow without running anything.
