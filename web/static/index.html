    Why this demo exists
    
    
    
      This UI is deliberately faithful and thin: its job is to make visible that meta-pipe's engine is a
      human + Claude-Code operator pausing at every reasoning step. A web wrapper around it is
      still that — a wrapper. By contrast, ebm-copilot
      is a server-side platform with its own database, orchestration and autonomous agents — a different architecture, not a UI skin.
