    About this interface
    
    
    
      This is a web interface for meta-pipe. Rather than auto-playing a polished run, it makes you
      clear every human gate yourself, so it is honest about how much operator input the pipeline needs:
      the research question, a hand-written search strategy, the pairwise-vs-network choice, the paywalled PDFs, and sign-off
      on extraction. At the screening stage it also shows the actual model and prompt meta-pipe uses — which
      you can edit and upload — so how the reviewer columns are produced is visible rather than assumed. It replays the bundled
      ici-breast-cancer example without running anything.
