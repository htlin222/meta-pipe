A web interface for the meta-pipe pipeline. There is no auto-play. First you prepare everything meta-pipe needs before it can run; then you advance one stage at a time, clearing each gate that exists in meta-pipe's own program by hand. Every gate cites its basis in the repo. At screening you can open and edit the actual LLM configuration meta-pipe uses. It replays the bundled ici-breast-cancer example — no API key, no execution.

    About this interface
    
    
    
      Rather than auto-playing a polished run, this interface makes you prepare the prerequisites and then
      clear each meta-pipe gate yourself, so it is honest about how much the pipeline depends on the operator.
      Every gate is grounded in meta-pipe's own program and cites its basis; gates we think are missing
      are kept separate, labelled as ours, and left off the pull request. At screening it also shows the
      actual model and prompt meta-pipe uses — editable and uploadable — so how the reviewer columns are
      produced is visible rather than assumed. It replays the bundled ici-breast-cancer example without running anything.
